    核心能力

    用语音安排日程，不必填写表单。

    用语音管理日程

    新建、查询、修改、删除日程，都可以用语音完成，不必在表单和日历之间来回切换。

    时间与地点

    支持到点闹钟，以及到达指定地点时的提醒。取快递、开会、路过某地，都可以设为提醒。

    云端写入，本地可见

    安排先保存在云端，再同步到本机。离线仍可查看日历，联网后自动同步。

    你的日程只属于你

    每个账号的日程相互隔离。语音功能需登录后使用。

    产品形态

    主界面是日历，语音入口在底部。

    主界面为月历与当日议程。底部语音栏左侧为免提通话，右侧为按住说话。免提通话进行中，按住说话会暂时停用，避免同时占用麦克风。

    • 月历圆点标出有安排的日子
    • 时间日程与地点提醒分开展示
    • 系统闹钟、后台定位，以及麦克风权限说明

    开源

    代码开源，可自行部署。

    客户端是 Expo 与 React Native，服务端是 FastAPI 与 PostgreSQL。语音使用通义实时模型，地点检索可接腾讯地图。可用 Docker Compose 启动数据库与 API。在 Android 上安装后即可使用语音功能。

    打开仓库 阅读上手说明
    • 客户端 Expo · React Native · TypeScript · SQLite
    • 服务端 Python 3.11 · FastAPI · PostgreSQL 16
    • 语音与地点 通义实时语音 · 腾讯地图检索

    关于 TimeFlow

    一只提醒你守时的小鸟。

    品牌由三个符号组成：时钟代表时间，小鸟代表陪伴与提醒，流线代表时间的流动。

    • 时钟

      代表时间

    • 小鸟

      代表陪伴与提醒

    • 流线

      代表时间在流动

    日程一多，真正耗神的往往不是不知道做什么，而是忙碌中仍要记住何时出发。

    对 TimeFlow 说出安排，即可写入日程并设置提醒。你可以继续当前工作，不必反复查看时间。

    时间临近时会按时提醒。若设置了地点提醒，到达公司或学校时，也会提示下一项安排。

    小鸟不是装饰，而是提醒：到点出现，把你带回安排。

    「明天下午三点有项目会议，提前十分钟提醒我。」

    距离项目会议还有十分钟。

    到点提醒；若设置了地点，到达时也会提示。
